# 动效补充说明

原版本只实现短暂图形入场和 CSS 悬停，未充分落实参考站的动态表现。此次对照 RQM+ 的实际页面、公开 `big-idea` / `cross-text` 脚本和浏览器连续帧，补充以下效果。

| 区域 | 新增表现 |
|---|---|
| 首屏文字 | 三行标题依次从遮罩内升起，说明与按钮分批出现 |
| 首屏品牌图形 | 背景横向滑入，HMC 三色圆弧旋入；各层以不同周期持续转动、中央圆点轻微呼吸；桌面有轻量鼠标跟随 |
| 正文 | 左右列滚动入场；新增三组“问题—行动”短句，文字与圆点按顺序出现 |
| 服务与团队 | 卡片错开进入，图标、箭头与装饰在悬停/键盘聚焦时响应 |
| 产品生命周期 | 连接线随滚动推进 |
| 图片与 CTA | 装饰和图片小幅随滚动位移，无强制滚动接管 |
| 客户评价 | 仅使用原站两条评价；自动轮播、上一条/下一条、圆点、暂停与键盘控制，保留截断提示 |
| 精选资源 | 桌面三张、平板两张、手机一张，支持箭头切换、触摸滑动和范围指示 |
| 导航 | 向下滚动收起，向上滚动出现；菜单和搜索面板带展开过渡 |
| 动效控制 | 右下角暂停/播放开关，选择跨页面保留；返回顶部按钮 |

GSAP / ScrollTrigger 负责入场和滚动场景，CSS 负责循环图形与微交互，React 控制轮播状态。参考的是动效机制，图形和色彩继续使用 HMC 品牌体系。

默认服务端正文可见，不使用全页 `opacity:0` 等待脚本。全局暂停和系统 `prefers-reduced-motion` 会关闭动态；无 JavaScript 时保持可阅读。首屏离开视口、页面进入后台时暂停循环；评价在悬停、键盘聚焦和离开视口时暂停。没有增加假业绩数字来模仿计数效果。

路由处理增加 Next.js 16 要求的 `data-scroll-behavior="smooth"`，避免页面跳转与 CSS 平滑滚动、ScrollTrigger 刷新互相干扰；验证了从资源区进入文章再返回首页的位置与动效恢复。

验证命令：

```powershell
npm run check
npm run build
npm test
node scripts/qa_motion.mjs
node scripts/qa.mjs
```

`qa/motion/report.json` 保存持续动画、滚动触发、暂停、轮播、路由切换、降动效、无 JavaScript 与六种宽度的验证。颜色对比在入场动画结束后检查，避免把过渡中的临时透明度当作最终文字样式。

`qa/reference-motion/` 是参考站本次只读检查的记录；`qa/motion/` 为实际 HMC 页面截图。

## 验证结果

动效专项 10/10 通过；360、390、768、1024、1440、1920 六种宽度无溢出和失效图片。原有 42 个页面/宽度组合、8 项交互和 5 页 axe 无障碍检查全部通过。源码构建与 9 项内容/接口测试通过。

动效版本地 Lighthouse：首页移动端 Performance 94、桌面端 100；Accessibility / Best Practices 均 100。SEO 69 的失败项仍为审阅版主动禁止索引。Vercel 已部署至原项目域名。

线上浏览器复核通过：持续动画、暂停/播放、评价切换、资源滑动及手机无横向溢出，未发现脚本错误。记录见 qa/motion/live-report.json。
