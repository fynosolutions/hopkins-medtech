# 5/6 图片描述与文件名

逐张查看了 27 项服务和 5 个行业的既有配图，添加描述画面本身的 imageAlt 和描述性文件名。首页、关于页、联系区块同步使用描述性别名。图片沿用原始字节；原始文件继续用于档案和历史链接，未删除。对照及 SHA-256 见 image-map.json。

不把素材人物、实验室或办公室说成 HMC 的真实人员或场地。真人头像继续使用首字母，未添加第二位管理层、照片或证书样张。团队头像组件的已有图片分支具备姓名、已确认头衔和公司名称的 alt。

类型检查和 24 项测试通过；生产构建通过。最终全站图片和移动端检查随第 6 个 PR 汇总。档案中的原始图片和历史文章缩略图保留原始出处，装饰性且 aria-hidden 的重复缩略图保留空 alt。
